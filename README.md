# superagnt plugins

superagnt is a marketing plugin for Claude and ChatGPT that helps businesses find customers through outbound, SEO and ads. This repo holds its Claude skills and plugins for marketing, with the live data they need. They work in Claude, Claude Code, Codex and ChatGPT.

A skill on its own is instructions. These run on live data out of the box:
LinkedIn, X, TikTok and YouTube, the open web, people and companies with
verified work emails, Google rankings and keywords, and a database that keeps
what each run finds. Connect superagnt once and every skill here has it.

## Install

### Claude and Claude Code

1. Add the superagnt server to Claude as a connector: [open the prefilled
   dialog](https://claude.ai/customize/connectors/yours?modal=add-custom-connector&connectorName=superagnt&connectorUrl=https%3A%2F%2Fmcp.superagnt.com%2Fmcp&open_in_browser=1) and click Add. The consent screen doubles as signup. One
   connector covers claude.ai, the desktop app, mobile, Cowork and Claude Code
   signed in with your Claude account. The desktop app only loads connectors
   when it starts, so refresh it with Cmd+R (Ctrl+R on Windows) or quit and
   reopen it after you approve.
2. Install the skills:

```
/plugin marketplace add superagnt/plugins
/plugin install superagnt@superagnt
```

In the Claude app, [add the plugin](https://claude.ai/customize/plugins/new?marketplace=superagnt%2Fplugins&plugin=superagnt) instead (plugins need a paid
plan). No tokens, no config editing, no secrets in this repo. Claude Code
signed in with an API key doesn't load connectors; use the fallback in the
setup guide, https://www.superagnt.com/install.

### Codex

The plugin carries the superagnt server for Codex. Add the base plugin, then
sign in through your browser:

```
codex plugin marketplace add superagnt/plugins
codex plugin add superagnt@superagnt
codex mcp login superagnt
```

### Any agent that reads SKILL.md files

The [skills CLI](https://skills.sh) installs one skill's folder into your
agent's skills directory:

```
npx skills add superagnt/plugins --skill <skill>
```

Connect the superagnt server to that agent too. The setup guide shows how for
each one: https://www.superagnt.com/install.

### ChatGPT

In ChatGPT on the web, go to Plugins, select the plus button, then Add custom MCP server. Name it superagnt, enter the server URL under Connection, and set Authentication to OAuth. The server URL is
`https://mcp.superagnt.com/mcp`. Tick "I understand and want to continue", then select Create as a plugin. Approve on the superagnt consent screen.
Install the plugin, then start a new chat, type @ and select superagnt. ChatGPT takes custom MCP servers on the web only, and OpenAI lists them for Business, Enterprise/Edu and Pro plans. Business and Enterprise/Edu workspaces get every tool, write actions included; an admin or owner adds the server there (on Enterprise/Edu, also a member they allow). Pro accounts get read and fetch actions only.

Each skill's setup guide, linked in the table above, takes ChatGPT and every
other client through running that skill.

## What's inside

- `plugins/superagnt/`: the base plugin. Eight base skills (data-sources,
  lead-generation, workspace-db, task-agents, automations, data-pipelines,
  dashboards, superagnt-setup) and the `/superagnt:connect` command. Its
  Codex copy also carries the MCP server config.
- `plugins/<skill>/`: one skill per packaged workflow, each with its own
  README. Read any skill before installing; they are plain markdown.

Two rules every skill follows: your agent can propose a plan upgrade when a
limit is reached, but money only ever moves on a confirmation page you open
yourself, and nothing goes out (email, posts, DMs) unless you ask for it or
approve it. The skills draft and stage, and campaigns stay stopped until you
start them.
